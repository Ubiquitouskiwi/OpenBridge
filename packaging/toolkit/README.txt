OpenBridge Rule Toolkit
=======================

Tools for people who know benefits policy or law to help check and improve
OpenBridge's rules. You do not need to know how to code. You do not need to
install anything, and you do not need the internet.

HOW TO START

  1. Unzip this folder.
  2. Double-click OpenBridge-Rule-Toolkit.html.
  3. It opens in your web browser. That's it.

  If it opens in the wrong program, right-click the file, choose "Open with",
  and pick your web browser (Chrome, Edge, Firefox, or Safari).

WHAT YOU CAN DO

  Review a state's rules
    See every rule value for a state in plain words, with the official source
    it came from (or a note that no source is listed yet). Mark each one as
    matching its source or not, add notes, and download a review report.

  Propose a rule change
    Pick a rule, enter the new value and the official source, and say why.
    The toolkit checks your entry and makes a proposal file for you.

  Check a test case
    Open a test case file and see whether OpenBridge gives the results you
    expect, with the math behind each one.

HOW TO SEND YOUR WORK

  Everything stays on your computer until you choose to share it.
  Attach the file you downloaded to a new GitHub issue using the
  "Eligibility rule correction" form on the OpenBridge repository,
  or email it to openbridge@starlingtek.com.

PLEASE NOTE

  OpenBridge is an early test version. Its rules are drafts that experts are
  still checking. Your review is part of that checking. Use made-up households
  for test cases, never a real person's details.

  Check BUILD-INFO.json for the version and the rules data version.
